# Night Garden

A tiny interactive field study of moths around a lamp. Move your pointer through the field, switch the wind preset, and change the glow or drift to alter the flight.

## Run it

Open `index.html` in a modern browser. No build step or package install is needed. Google Fonts load when you have an internet connection; the page falls back to system fonts otherwise.

## Controls

- Move the pointer over the field to nudge nearby moths.
- Choose Still air, Breeze, or Gather to change the movement.
- Adjust Wind drift and Lamp glow.
- Pause or resume the animation from the footer.

Built with HTML, CSS, Canvas, and plain JavaScript.
